Sound Rekorder - nimmt den Ton vom PC auf (kein Video)
Aufnahmen landen in:  Musik\Sound

Variante 1: Fertige .exe per GitHub bauen lassen
  1. Neues GitHub-Repo anlegen und ALLE Dateien hochladen (auch den Ordner .github).
  2. Reiter "Actions" > "Windows-App bauen" abwarten.
  3. Unten bei "Artifacts" Sound-Rekorder-Windows herunterladen, entpacken, Installer oder portable .exe starten.

Variante 2: Auf dem PC mit Node.js (npm install, dann npm start / npm run dist)
